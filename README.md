MD1RoBoT 🧬

محرك تطور ذاتي متعدد اللغات يعمل محليًا بالكامل، بدون أي واجهة خارجية مدفوعة.
يحلل الكود، يقترح تحسينات، ويطبقها تلقائيًا عبر حلقة تطور مستمرة — نماذج محلية فقط، بلا API مدفوع.

🎯 الهدف

نظام Agentic Evolution يطوّر أي مشروع برمجي بأي لغة (أو مزيج لغات)، معتمدًا على نماذج محلية عبر Ollama، وأدوات تحليل ثابت ومترجمات حقيقية لتقييم موضوعي — لا "رأي" من نموذج لغوي بس.

الفلسفة: كل تعديل بيمر بدورة ، مش مجرد "جرّب وشوف". النجاحات بتتراكم كمعرفة قابلة لإعادة الاستخدام، مش سجل تصحيحات منفصل عن بعضه.ملاحظة → فرضية → طفرة → تجربة → تقييم → معرفة

🚫 القيود الجوهرية (غير قابلة للتجاوز)
ممنوع أي تعديل يستهدف تعطيل/حذف الوحدات الأساسية
ممنوع أي محاولة استنساخ أو نشر ذاتي على خوادم خارجية
لا Abliteration على أي نموذج داخل Brain/Kreza — توجيه هندسي صارم (system prompt محكم) بديل أأمن وأفعل، لأن كسر توازن النموذج بيقلل التزامه بالتعليمات مش بس "الفلاتر"
