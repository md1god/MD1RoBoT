# MD1RoBoT 🧬

**محرك تطور ذاتي متعدد اللغات يعمل محلياً بالكامل بدون واجهات خارجية مدفوعة.**  
يقوم بتحليل الأكواد، اقتراح تحسينات، وتطبيقها تلقائياً عبر حلقة تطور مستمرة، باستخدام نماذج ذكاء اصطناعي محلية وأدوات فحص مفتوحة المصدر.

---

## 🎯 الهدف

- نظام **Agentic Evolution** قادر على تطوير أي مشروع برمجي مكتوب بأي لغة (أو مزيج من اللغات).
- يعتمد على نماذج محلية (Ollama) مثل `Qwen2.5-Coder`، `DeepSeek-Coder`، `CodeGemma` ولا يستخدم أي API مدفوع.
- يستخدم أدوات تحليل ثابت ومترجمات حقيقية لتقييم جودة الكود بشكل موضوعي.
- يعمل داخل حاوية Docker واحدة تحتوي على كل شيء (Rust + Ollama + أدوات اللغات).

## 🔁 دورة التطور (Evolution Loop)

1. **بناء السياق** (`ContextBuilder`): تجميع أحدث حالة للمشروع (جيل، لياقة، أهداف، موارد).
2. **توليد الطفرات** (`Crazy`): النموذج المحلي يقترح تعديلات على الكود (3-5 اقتراحات).
3. **التجارب المختبرية** (`EvolutionLab`):
   - نسخ المشروع إلى مجلد مؤقت.
   - تطبيق التعديل المقترح.
   - محاولة البناء والتشغيل بلغة الملف (يكتشف اللغة تلقائياً).
   - جمع Phenotype: وقت البناء، نسبة الأخطاء، استهلاك الذاكرة.
4. **التقييم** (`Kreza`):
   - تحليل واقعي: هل نجح البناء؟ هل تحسنت اللياقة؟ ما المخاطرة؟
   - استشارة نموذج لغوي عند الحاجة.
   - إصدار حكم: Approve / Reject / Modify / NeedsExperiment / Rollback.
5. **تطبيق أفضل طفرة** (`Planner`):
   - حفظ نسخة احتياطية.
   - دمج التعديل في المشروع الحقيقي.
   - تسجيل النجاح/الفشل في قاعدة البيانات.
   - تحديث الجيل واللياقة.
6. **بحث وإثراء** (`Seed` اختياري): جلب معلومات من الويب لتوسيع المعرفة.
7. **الرجوع إلى الخطوة 1**.

## 🧠 النماذج المحلية (Model Routing)

- **Qwen2.5-Coder (7B)**: ممتاز للغات Python, JavaScript, TypeScript.
- **DeepSeek-Coder (6.7B)**: قوي في Rust, C, C++, والخوارزميات.
- يمكن إضافة نماذج أخرى بسهولة عبر تعديل `ModelRouter`.

الموجّه يختار النموذج بناءً على:
- امتداد الملف (`.py`, `.js`, `.rs`, `.c` ...)
- نوع المهمة (`GenerateMutation`, `EvaluateMutation`, ...)
- حجم السياق (يُفضَّل نموذج بنافذة سياق كبيرة للمشاريع الكبيرة)

## 🌐 تعدد اللغات

`EvolutionLab` يستخدم جدولاً داخلياً لاختيار الأمر المناسب حسب لغة الملف:

| اللغة       | أمر البناء/التحقق                  |
|-------------|-----------------------------------|
| Rust        | `cargo check` / `cargo test`     |
| Python      | `python -m py_compile` + `pylint`|
| JavaScript  | `node --check` + `eslint`        |
| C/C++       | `gcc -fsyntax-only` / `make`     |
| عام         | `semgrep` لتحليل ثابت متعدد      |

## 🗄️ قاعدة البيانات (SQLite)

- **جدول `genomes`**: يخزن كل طفرة ناجحة مع لياقتها.
- **جدول `mutation_history`**: سجل كامل بكل تجربة (ناجحة/فاشلة) مع الأخطاء.
- **جدول `knowledge`**: المعرفة المكتسبة من البحث.
- **جدول `oscillation_log`**: منع التكرار والتذبذب.
- **جدول `long_term_memory`**: ذاكرة دائمة للخبرات.
