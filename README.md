# MD1RoBoT Voice — مشروع الصوت المصري

## الهدف
Zero-shot voice cloning بلهجة مصرية باستخدام VoiceTut-TTS، شغال على Colab/Kaggle
(GPU مجاني)، بدون أي تكلفة مالية.

## هيكل الريبو
```
notebooks/          # كود Colab/Kaggle (نفس الكود يشتغل على الاتنين)
data/
  voices/            # ملفات الصوت المرجعية (ميمي، سوسو) — لو حبيت ترفعهم هنا
  lexicon.json        # تصحيحات نطق الكلمات (مش أسرار، آمن يترفع للريبو)
scripts/             # أي سكريبتات مساعدة مستقبلية
.github/workflows/    # تنبيه تليجرام لما حاجة تتحدث
PROGRESS.md          # سجل تجارب يدوي — سطر واحد كل جلسة
```

## ليه مفيش تشغيل أوتوماتيك كامل؟
GitHub Actions مقدرش يفتح جلسة Colab نيابة عنك — محتاج تسجيل دخول Google
يدوي. الـ workflow هنا بيبعتلك بس تنبيه تليجرام لما حاجة تتحدث في الريبو،
وإنت اللي بتفتح Colab/Kaggle يدوياً وتشغل.

## طريقة الاستخدام
1. أي تعديل على النص/الصوت/الكود — اعمله commit وpush على الريبو
2. هتوصلك رسالة تليجرام تفكرك تفتح Colab
3. افتح `notebooks/voicetut_colab_test.py`، انسخ الكود لـ Colab
4. بعد الجلسة، سجّل سطر في `PROGRESS.md` وارفعه (commit)

## ملاحظة مهمة عن الملفات الصوتية
متترفعش أي صوت مصدره ElevenLabs أو أي منصة تجارية للريبو العام من غير
مراجعة شروط الاستخدام بتاعتهم الأول — لو الريبو عام (public)، أي حد
هيقدر يشوف/يحمل الملفات دي.
